TRE GPS レンタルの料金と端末の選び方

TRE GPS レンタル公式サイトの料金表・商品一覧の記載をもとに、4機種の料金と仕様、レンタル期間の数え方を整理しています（2026年11月17日確認）。

結論：最も小さい Type U は1日3,190円・30日6,881円（税込）。月額契約なしで、旅行や行事など期間を決めて使うためのサービスです

TRE GPS レンタルは、小型GPS端末を最短1日から借りられるサービスです。料金はレンタル期間分だけで、公式の料金表では送料・位置検索・サポートは0円からと表示されています。期間は商品到着日の翌日から数え、返却は期間終了後2日以内の消印有効です。延滞すると1日3,300円／台かかるため、日程に余裕を持ったお届け日の指定が重要です。

申し込みから返却までの流れ

  1. GPS端末・オプション・お届け日を選んで申し込みます。お届け日を指定しない場合は、平日12時までの申し込みで当日出荷（最短翌日着）、12時以降は翌平日の出荷です。出荷は平日のみです。
  2. 端末は初期設定を済ませた状態で届きます。届け先はご自宅以外（親族宅・勤務先・営業所など）も指定できます。
  3. 商品到着日の翌日からレンタル期間が始まります。
  4. 期間終了後2日以内の消印有効で、ポスト投函により返却します。期限を過ぎた消印は1日あたり税込3,300円／台の延滞料金がかかります。

銀行振込の場合、お届け日を指定したお申し込みは、申込日から3日以内に振込を確認できないと自動キャンセルになると案内されています。

よくある質問

レンタル期間はいつから数えますか？
公式サイトでは、商品到着日の翌日からレンタル期間が始まると案内されています。不在で受け取れなかった場合も、レンタル期間は翌日から始まります。使い始める日が決まっている場合は、お届け日の指定が勧められています（2026年11月17日確認）。
返却が遅れるとどうなりますか？
返却はレンタル期間終了後2日以内の消印有効で、ポスト投函で返却できます。返却期限を過ぎた消印の場合は、1日あたり税込3,300円／台の延滞料金がかかると公式サイトに記載されています。
子どもに持たせるならどの機種ですか？
公式の商品一覧では、Type U が「サイズ重視」（47×40×17mm・42g）、Type P は「車両専用モデル」（300g）と案内されています。子どもに持たせる用途では、小型の Type U、充電持ちを重視する場合は拡張バッテリー付きの Type U+ が候補になります。Type U+ のサイズ・重さは、確認した比較表に記載がありませんでした。
海外でも使えますか？
Type U・Type U+ は、オプションの「海外対応変更」（3,300円）で、全世界160以上の国と地域で使える端末に変更できると案内されています。Type S・Type P は国内のみです。中国では、専用アプリが使う Google マップを利用できない場合があり、VPN対応WiFiの持参が推奨されています。
端末をなくした場合の費用は？
オプションの「紛失故障安心パック」に加入すると、端末の弁済金の80〜100％が免除されると案内されています。最低加入料金は5日プランの設定で、30日以上のプランは一律料金です。具体的な金額はお申し込み画面でご確認ください。

出典：TRE GPS レンタル「トップページ」「料金表」「商品一覧」（2026年11月17日確認）
